# Amanda Beauty

Site demonstrativo responsivo para um espaço de beleza. Abra `index.html` em um navegador; as páginas compartilham `styles.css`, `app.js` e as imagens dentro de `assets/`.

## Páginas

- Início com carrossel das três imagens de referência
- Serviços com filtros por categoria
- Nosso espaço
- Agendamento
- Login em janela pop-up, acessível pelo botão “Entrar” em qualquer página
- Cadastro

Login, cadastro e envio de agendamento são demonstrações no navegador. Para receber reservas e autenticar clientes, conecte um backend e um canal de atendimentos.
